# Skinstric.AI — AI-Powered Skin Analysis

Analyze and visualize skin health through real-time camera capture and AI integration.

[Live Demo](https://skinstric-ai-two.vercel.app/) • [Repository](https://github.com/kingkey0101/Skinstric-ai)

---

## Overview
Skinstric.AI is a responsive React application that allows users to capture live images, encode them in Base64, and prepare them for AI-based skin analysis. It showcases advanced browser permission handling, smooth GSAP animations, and production-level UI precision.

---

## Tech Stack
- **Frontend:** React.js, TailwindCSS, JavaScript (ES6+)
- **Libraries:** GSAP, React-Webcam, Axios
- **Tools:** FileReader API, Git, GitHub, Vercel (CI/CD deployment)

---

##  Features
-  Live webcam access with user permission flow  
-  Base64 image encoding for AI-ready processing  
-  GSAP hero animation and dynamic text transitions  
-  Fully responsive, pixel-accurate layout  
-  Lazy-loaded assets for optimized performance  

---

## Key Learnings
- Implementing webcam capture and permission logic in React  
- Managing asynchronous image data and encoding  
- Creating motion-driven UIs with GSAP  
- Writing clean, modular, and scalable React components
